# Mountain Landing Page — HTML & CSS
## ملفات المشروع

| الملف | وظيفته |
| --- | --- |
| `index.html` | الصفحة الرئيسية: صورة الجبال مع عبارة Hello There وثلاث بطاقات Feature. |
| `agency.html` | صفحة إضافية تمثل نموذج الوكالة: ثلاث خطوات عمل وقسم Services. |
| `style.css` | ملف التنسيقات المشترك: الألوان، الخلفيات، Grid، الخطوط، ومسؤولية عرض العناصر على الأجهزة المختلفة. |
| `landing.jpg` | الصورة التي تُستخدم كخلفية في مقدمة الصفحتين. |

## كيفية التشغيل

1. نزّل المشروع وفك ضغطه إن لزم.
2. احتفظ بالملفات الأربعة في المجلد نفسه.
3. افتح **`index.html`** في أي متصفح، أو استخدم Live Server في Visual Studio Code.
4. افتح **`agency.html`** لمعاينة الصفحة الإضافية.

## شرح أجزاء الكود

### HTML

- `<!DOCTYPE html>`: يحدد استخدام HTML5.
- `<head>`: يضم إعداد الترميز، إعداد الشاشة للهواتف، العنوان، ورابط ملف CSS.
- `<main>`: يحتوي المحتوى الرئيسي للصفحة.
- `<section class="hero">`: منطقة الترحيب أعلى `index.html`، وخلفيتها صورة الجبال من خلال CSS.
- `<section class="features">`: ثلاثة عناصر `<article>`، لكل عنصر أيقونة SVG وعنوان ووصف.
- `<section class="process">`: خطوات العمل الثلاث في `agency.html`.
- `<section class="services">`: الخدمات مع شبكة داخلية لبطاقات الخدمة.
- التعليقات المكتوبة بصيغة `<!-- ... -->` توضح أقسام HTML.

### CSS

- `:root`: متغيرات الألوان المستخدمة في المشروع.
- `.hero` و`.agency-banner`: طريقة ظهور صورة الجبال كخلفية `background-image`.
- `.features__grid` و`.process__grid`: استخدام `display: grid` لعمل ثلاثة أعمدة متساوية.
- `.services__layout`: تقسيم منطقة الخدمات إلى عمود للمحتوى وآخر لشكل توضيحي.
- `@media`: تحسين التنسيق للشاشات الصغيرة باستخدام Responsive Design.
- التعليقات المكتوبة بصيغة `/* ... */` توضّح مجموعات التنسيقات.

## خطوات الرفع على GitHub

1. سجّل الدخول إلى [github.com](https://github.com/).
2. أنشئ مستودعًا جديدًا (New repository)، وليكن اسمه `mountain-html-css` واجعله **Public** إذا طلب الدكتور رابطًا قابلًا للمشاهدة.
3. ارفع `index.html`, `agency.html`, `style.css`, `landing.jpg`, `README.md` إلى **جذر المستودع** (وليس داخل مجلد فرعي).
4. اضغط **Commit changes** ثم انسخ رابط المستودع، مثل `https://github.com/USERNAME/mountain-html-css` بعد استبدال `USERNAME` بحسابك الحقيقي.
5. اختياريًا، لتشغيل الموقع على الإنترنت: Settings > Pages > Deploy from a branch > main > /(root) > Save. بعد النشر سيظهر رابط GitHub Pages، ويمكن إضافته إلى التسليم إن أردت.

## ملاحظات

- يجب أن يكون التسليم النهائي **رابط GitHub حقيقي** وليس رابط ملف ZIP فقط.

- لم يتم رفع المستودع إلى حساب GitHub ضمن هذه النسخة المحلية.
